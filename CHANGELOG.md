# Changelog

## 0.1.0

First public version.

- NTFS scanning straight from the MFT, cache of file records and incremental updates from
  the USN journal.
- Live updates of the tree in place, with three modes: never, while the window is active,
  always.
- Tree, file types and treemap views, name search, duplicate finder.
- Explorer context menu, deletion, clipboard, CSV and PNG export.
- Directory walk for FAT32, exFAT, ReFS, network shares and folders.
- Light and dark theme, English and Russian interface.
- Portable: settings and cache next to the executable.
